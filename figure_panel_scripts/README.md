# Figure panel scripts

Copies of the scripts that generate the code-produced panels of the three
manuscript figures, renamed `fig<N><panel>_*`. Figures are numbered in the order
shown:

- **Fig 1** — platform overview (Xenium 280 / Atera / Xenium 5K)
- **Fig 2** — myeloid / immune-niche
- **Fig 3** — inferCNV / clonal

Originals are unchanged; these are copies. Panels that are **not** generated by
code (microscopy images, schematics, and outputs from external pipelines) are
listed below as omitted, per instruction.

> **Numbering note.** Fig 1–3 below were numbered in the order the images were
> shown. The user-supplied `fig2_atera_vs_xenium.R` (platform cell-type
> comparison) and `fig5abcd_*` / `fig4g_*` (immune-niche/clone co-evolution) use
> the real manuscript numbering, so **two "Fig 2" analyses currently coexist**:
> the platform comparison (new) and the legacy image-order "Fig 2 — myeloid"
> section below. The myeloid/immune distance boxplot (panel g) has been resolved
> to **Fig 4** (`fig4g_distance_dc.py`); the remaining image-order labels are
> still to be reconciled with the real manuscript numbering.
